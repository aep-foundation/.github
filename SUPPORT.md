# Support

## Questions and protocol design

Use [AEP Discussions](https://github.com/aep-foundation/aep-specs/discussions) for usage questions, protocol-design discussions, and questions that span the specification and implementation.

## Defects and feature proposals

Open an issue in the repository that owns the affected behavior. Protocol and wire-format proposals belong in [`aep-specs`](https://github.com/aep-foundation/aep-specs/issues). Node.js SDK and integration defects belong in [`aep-node`](https://github.com/aep-foundation/aep-node/issues).

Include a minimal reproduction, the affected version, and the expected behavior.

## Security vulnerabilities

Do not open a public issue. Follow the `SECURITY.md` instructions in the affected repository.
