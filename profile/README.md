# Agent Enrollment Protocol

The Agent Enrollment Protocol (AEP) is an open protocol for onboarding agents to services. It defines discovery,
enrollment, lifecycle status, session-credential grants, revocation, and authentication of protected resources.

AEP lets services establish relationships with agents without coupling either party to one identity host, credential
format, or application framework. Its protocol specifications, schemas, examples, test vectors, conformance tooling,
and reference implementations are under active development.
